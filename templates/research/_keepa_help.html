How to get the Keepa file (no API needed)
  1. Sign in at keepa.com (a Data subscription is needed to export).
  2. Open Product Finder (or Category Tree) and filter to your product’s niche/category on Amazon.co.uk.
  3. Add these columns before exporting: ASIN, Title, Brand, Buy Box (Current / Lowest / Highest / 90-day avg), Sales Rank, Reviews Rating, Review Count, Bought in past month, Categories (Root/Sub/Tree), Color, Size, Variation ASINs, Package dimensions & weight, Features/Description.
  4. Click Export → CSV/XLSX and download the file.
  5. Upload it below. Rows are matched by ASIN; any product not in the file is marked “Unknown” (Rule 0). Missing variation ASINs can be added by running a Keepa lookup on them and re-uploading a combined export.
